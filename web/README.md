# Crucible dashboard

The Next.js app behind the product: replay recorded calls, hear the audio, read
what the customer said beside what the agent's recogniser heard, and open the
scored report. The API routes under `app/api/` read run artifacts from `../runs/`.

Run it: `npm install && npm run dev` (port 3000). Full developer notes live in
[../docs/DEVELOPMENT.md](../docs/DEVELOPMENT.md).
